## Реализация (новый код)

### 1. NavGrid: 5-й весовой слой для overlay-cost (шаг 8, ядро)
**Файл:** `game/features/routing/application/nav_grid.gd`

Аддитивное изменение по образцу `_profile_cell_weights` (nav_grid.gd:179-190):
- Поле `var _overlay_cell_weights: Dictionary = {}` (cell: Vector2i → multiplier float, ≥0.1).
- `func set_overlay_cell_weights(next: Dictionary)` — sanitizer + bump `_revision`/`_weights_revision` (как `set_profile_cell_weights`), **без** `_topology_revision` (cost — не проходимость).
- В `get_cell_weight()` (nav_grid.gd:233): `return _surface_weight(cell, profile) * _slope_cost_factor(...) * _overlay_factor(cell)`.
- `func _overlay_factor(cell) -> float`: `float(_overlay_cell_weights.get(cell, 1.0))`, зажать в `[MIN_CELL_WEIGHT, MAX_CELL_WEIGHT]`.
- `func erase_overlay_cell_weights()` — для сброса при перезагрузке.

**Почему слой в NavGrid, а не декоратор солвера:** cost-читает один чокпойнт `get_cell_weight` (nav_grid.gd:233), а `set_profile_cell_weights` уже доказывает этот паттерн. §4.1 явно: `deny`/`cost` ≠ проходимость, `is_walkable` не трогается → revision-контракт (только weights, без topology) соблюдён. ~20 строк.

### 2. ZoneOverlayIndex — индекс клеток покрытия (новый класс)
**Файл:** `game/features/world/domain/map/zone_overlay_index.gd` (`class_name ZoneOverlayIndex extends RefCounted`)

Преобразует `areas[]` (overlay-роли) в Dictionary ячейка→комбинированные эффекты:
- `func rebuild(zones: MapZoneLayer, board_cells: int) -> void` — для каждого overlay-area: по `footprint_cells()` собрать `effects` через `ZoneEffects.combine`, хранить в `_cell_effects: Dictionary[Vector2i, Dictionary]`.
- `func cost_at(cell) -> float` — `float(_cell_effects.get(cell, {}).get(ZoneEffects.KEY_COST, 1.0))`.
- `func denies_visitor(cell) -> bool` — для overlay с `deny` содержащим `visitor` или `*` (§4.1: deny сильнее allow, `*` = все). Заглушка под tag-issuer.

**Без audience-scoped cost** (§4.2 опционально — отложено). Single combined cost на клетку.

### 3. OverlayNavigationPublisher — публикует overlay-cost в NavGrid (новый класс)
**Файл:** `game/features/world/application/overlay_navigation_publisher.gd` (`class_name OverlayNavigationPublisher extends RefCounted`)

Прямой аналог `TerrainNavigationPublisher`, но проще (без инкремента/delta — overlay-разметка статична в сессии):
- `func configure(overlay_index: ZoneOverlayIndex, nav_grid: NavGrid) -> void`
- `func publish_all() -> void` — собирает `cell → cost` из индекса, вызывает `nav_grid.set_overlay_cell_weights(dict)`.

### 4. Валидация §8.1 (rest) — без NavGrid-reachability (его некуда положить)
`map_validator.gd` не существует (только спека §11, фаза 6). Создавать весь валидатор ради reachability — превышение объёма. **Поэтому:**
- Reachability/вода/дыры (§8.1 L352, L359-360) — **откладываются** до `map_validator.gd` (отдельный раунд, фаза 6).
- In-layer часть §8.2 (предупреждения) — добавить в `MapZoneLayer` отдельный метод `warnings(board_cells)`: «область, на которую никто не ссылается» (L368). Ошибки и предупреждения разделить, как требует §8.

### 5. SpawnService — чтение spawn-якорей (шаг 15, видимый результат)
**Файл:** `game/features/world/application/map_spawn_service.gd` (`class_name MapSpawnService extends RefCounted`)

- `func spawn_positions(zones: MapZoneLayer, board_cells: int) -> Array[Vector3]` — все `spawn`-якоря с корректным `pos.y` (clamp к terrain, если доступен). Пустой массив = fallback к хардкоду.
- `func first_spawn_position(zones, fallback: Vector3) -> Vector3` — первый spawn-якорь или fallback.

**Без tag-фильтрации** пока (требует tag-issuer, отложен). Все spawn-якори равноценны.

## Рамки (от AGENTS.md / спецификации)
- `class_name`, не `preload` — все новые классы объявляют `class_name`.
- Одна точка записи на механику — overlay-cost публикуется **только** через `OverlayNavigationPublisher`, как и terrain только через `TerrainNavigationPublisher`.
- `SettlementGame` без скрытого API — новые сервисы (`MapSpawnService`) — public-поля/параметры, не `_`-методы.
- Движок не читает `function` — spawn-операция читает только `role == ROLE_SPAWN` (§15: «движок функцию не читает»).
- Static nodes в `.tscn` — новые сервисы — `RefCounted`, инстанцируются в bootstrap (как `TerrainNavigationPublisher`).
