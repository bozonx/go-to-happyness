# План: MapZoneRegistry — runtime-состояние зон карты (§13), in-memory

Объём зафиксирован вашими ответами: **только registry (owner/flags), без шины событий, без presence-трекера, без persistence**. Чистое runtime-ядро §13, которое станет фундаментом под шину (§14) и persistence в следующих блоках.

## Что НЕ делается (явно отложено)
- `ZoneEventBus` (§14) и presence-события — следующий блок, когда есть потребители.
- `ZonePresenceTracker` + cell-diff в `guard_citizen_positions` — вместе с шиной.
- Save/load: registry живёт в памяти, не переживает сессию. Слот `map_zones` в SaveData не добавляется. Каждый запуск — свежее состояние.
- Теги действующего (§12): `owner` хранится как opaque `StringName`, но нет tag-issuer; `is_owned_by` работает как membership-check, как и на building-стороне.
- Резервации слотов (map region не владеет слотами — это дело зданий).

## Реализация

### 1. MapZoneRuntimeState (domain) — зеркало ZoneRuntimeState, session-only
**Файл:** `game/features/world/domain/map/map_zone_runtime_state.gd` (`class_name MapZoneRuntimeState extends RefCounted`)

Session-only состояние одной зоны карты (region/overlay). По контрасту с `ZoneRuntimeState` у неё **нет** definition-полей slots/queue/storage/fallback_pos — определение живёт в `MapZoneLayer`. Только то, что партия меняет (§13):

- Поля: `zone_id: StringName`, `owner_tag: StringName = &""`, `flags: Dictionary = {}`.
- `static func from_definition(area: ZoneAreaRecord) -> MapZoneRuntimeState` — строит по id из области.
- `func apply_session_state(data: Dictionary) -> void` — накладывает сохранённые owner/flags (defensive: unknown keys игнорируются; для будущего persistence).
- `func is_owned_by(agent_tags: Array) -> bool` — копия из `zone_runtime_state.gd:206` (relational owner audience §12).
- `func set_owner(new: StringName) -> bool` / `func set_flag(key, value) -> bool` / `func flag(key, fallback)` — no-op short-circuit pattern (как `zone_runtime_state.gd:210-225`).
- `func session_state_to_dict() -> Dictionary` — `{id, owner, flags}` (для будущего persistence; сейчас не вызывается, но форма зафиксирована).
- `func to_dict() -> Dictionary` — alias session_state_to_dict (нет отдельной definition-части).

**Mirror из `zone_runtime_state.gd`:** форма класса, no-op setters, is_owned_by, session_state_to_dict. **Опущено:** slots/queue/storage/reservations/capacity/assign — map region этим не владеет.

### 2. MapZoneRegistry (application) — зеркало BuildingRuntimeState, без node-meta
**Файл:** `game/features/world/application/map_zone_registry.gd` (`class_name MapZoneRegistry extends RefCounted`)

- `var _states: Dictionary = {}` — `zone_id (StringName) → MapZoneRuntimeState`. Dictionary, а не Array (map может содержать десятки регионов; линейный scan как в building — ok, но dict чище).
- `func build_from(zones: MapZoneLayer) -> void` — для каждого `area` создаёт `MapZoneRuntimeState.from_definition(area)` и кладёт в `_states`. Идипотентно: `clear()` + rebuild.
- `func state(zone_id) -> MapZoneRuntimeState` — lookup, null если нет.
- `func owner_of(zone_id) -> StringName` / `func flag_of(zone_id, key, fallback) -> Variant`.
- `func set_owner(zone_id, owner_tag) -> bool` / `func set_flag(zone_id, key, value) -> bool` — mutate + return changed (no-op short-circuit). **Без commit-шага** (нет node-meta — состояние в памяти).
- `func is_owned_by(zone_id, agent_tags) -> bool`.
- `func session_state_to_dict() -> Array` — `[state.session_state_to_dict() for state in _states.values()]` (для будущего persistence; сейчас не вызывается).

**Mirror из `building_runtime_state.gd`:** контейнер + lookup + `zone_by_id`. **Опущено:** `from_node`/`apply_to_node` (нет node-meta — состояние в памяти), `permits`/`effects_at` (это уже делает `ZoneOverlayIndex` из прошлого блока).

### 3. MapZoneService (application) — тонкий фасад (как BuildingZoneService)
**Файл:** `game/features/world/application/map_zone_service.gd` (`class_name MapZoneService extends RefCounted`)

Stateless фасад над registry (зеркало `building_zone_service.gd`). Пока минимум, нужный правилам будущего:
- `var _registry: MapZoneRegistry`
- `func configure(registry: MapZoneRegistry) -> void`
- `func set_owner(zone_id, owner_tag) -> bool` / `func owner_of(zone_id) -> StringName`
- `func set_flag(zone_id, key, value) -> bool` / `func flag_of(zone_id, key, fallback) -> Variant`
- `func is_owned_by(zone_id, agent_tags) -> bool`

**Без** `work_position`/`release_slot`/`reconcile_assignments` — map region ими не занимается.

### 4. Wire-in: SettlementGame + SettlementBootstrapper

## Рамки
- `class_name`, не `preload`.
- Одна точка записи: `MapZoneRegistry` — единственный владелец session-state зон карты; `MapZoneService` — единственный фасад (как `BuildingZoneService` для зданий).
- SettlementGame без скрытого API: `map_zone_registry`, `map_zone_service` — public поля.
- RefCounted, инстанцируется в bootstrap (как `TerrainNavigationPublisher`, `MapSpawnService`).
- Движок не читает `function`: registry оперирует только `id`/`owner`/`flags`, не интерпретирует смысл зоны (§2).
